ELITE FORCE MINI APP — Render

Файлы: index.html, server.js, api.mjs, package.json.
Render: Build Command = npm install; Start Command = npm start; Node >=20.

ОБЯЗАТЕЛЬНЫЕ ENVIRONMENT VARIABLES:
TELEGRAM_BOT_TOKEN — токен из BotFather (никому не отправлять).
TELEGRAM_BOT_USERNAME — username бота без @.
ADMIN_TELEGRAM_ID — числовой Telegram ID администратора.
TELEGRAM_CHANNEL_ID — ID канала (обычно -100...); добавьте бота администратором канала.
TELEGRAM_CHANNEL_URL — публичная ссылка на канал, например https://t.me/yourchannel.
DATA_DIR=/var/data

ВАЖНО: добавьте на Render Persistent Disk с Mount Path /var/data, иначе JSON-база может пропасть после перезапуска/пересборки.

РЕФЕРАЛЬНАЯ СИСТЕМА:
По умолчанию пригласивший получает 70 монет, приглашённый — 35. Награды начисляются после того, как приглашённый откроет Mini App по ссылке ref_<Telegram ID> и пройдёт серверную проверку подписки на канал. Повторная выдача за тот же Telegram ID блокируется. Для корректной работы бот должен иметь доступ к getChatMember в канале.

ЗАДАНИЕ НА ПОДПИСКУ:
Кнопка «Перейти» открывает TELEGRAM_CHANNEL_URL. После подписки пользователь возвращается в Mini App и нажимает «Проверить». Сервер проверяет членство через Telegram Bot API. За успешное выполнение начисляется 50 монет один раз.

РУЛЕТКА:
По умолчанию максимум 10 прокруток в сутки, первые 3 бесплатные, остальные по 100 монет. Настраивается в админ-панели. Вероятности можно менять; значения трактуются как относительные веса и нормализуются автоматически.

АДМИН-ПАНЕЛЬ:
Доступ только пользователю, чей ID указан в ADMIN_TELEGRAM_ID. Настройки вероятностей, цен, остатков, лимита прокруток и реферальных наград сохраняются в JSON-файле на DATA_DIR.

ПЕРЕД ЗАПУСКОМ:
1) Укажите все ENVIRONMENT VARIABLES выше.
2) Создайте Persistent Disk и задайте DATA_DIR=/var/data.
3) Добавьте бота администратором канала.
4) Убедитесь, что бот открывает Mini App кнопкой меню или Web App-кнопкой. Одна команда /start?start=... сама по себе не открывает Mini App.
5) Проверьте в тесте: задание на подписку, реферал, прокрутки, сохранение админ-настроек после рестарта.

Примечание: Telegram initData проверяется сервером. Токен не хранится в клиентском HTML.
